# CampusSchedule — Progressive Web App (PWA)

ระบบตารางเรียนและตารางสอบอัจฉริยะ (PWA) สามารถติดตั้งลงบนมือถือ (Android / iOS) และคอมพิวเตอร์ (Chrome / Edge / Safari) พร้อมระบบแจ้งเตือนเข้ามือถือได้เหมือนแอปแท้

---

## 📁 ไฟล์สำคัญในโปรเจกต์
- `index.html` / `table.html` : หน้าเว็บตารางเรียนหลัก ออกแบบรองรับมือถือและคอม พร้อมปุ่มติดตั้งแอปและเปิดแจ้งเตือน
- `manifest.json` : การตั้งค่าแอป PWA (ชื่อแอป, ไอคอน, สีธีม, โหมด standalone เต็มจอ)
- `sw.js` : Service Worker สำหรับแคชไฟล์ออฟไลน์ และดักรับ Push Notification เข้าเครื่อง
- `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` : ไอคอนสำหรับติดตั้งบนหน้าจอโฮม
- `api/push.js` : ตัวอย่างโค้ด Serverless Function บน Vercel สำหรับยิง Push Notification จากหลังบ้าน

---

## 📲 วิธีติดตั้งลงบนมือถือ

### 1. บน Android (Google Chrome / Edge)
1. เปิดเว็บไซต์ผ่าน Chrome
2. จะมีปุ่ม **"📲 ติดตั้งแอป"** เด้งขึ้นมา หรือแตะจุด 3 จุดมุมขวาบน $\rightarrow$ เลือก **"ติดตั้งแอป (Install app)"**
3. ไอคอนจะไปปรากฏบนหน้าจอโฮมของคุณเหมือนแอปทั่วไป

### 2. บน iPhone / iPad (Safari)
*(รองรับ iOS 16.4 ขึ้นไปสำหรับการแจ้งเตือน)*
1. เปิดเว็บไซต์ผ่านเบราว์เซอร์ **Safari**
2. แตะปุ่ม **แชร์ (Share)** ที่แถบด้านล่าง (ไอคอนสี่เหลี่ยมมีลูกศรชี้ขึ้น `[⎋]`)
3. เลื่อนลงมาเลือก **"เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)"**
4. เปิดแอปจากไอคอนบนหน้าจอโฮม จากนั้นกดปุ่ม **"🔔 เปิดแจ้งเตือน"**

---

## 🔔 ระบบแจ้งเตือนตารางเรียน (Notifications)
1. กดปุ่ม **"🔔 เปิดแจ้งเตือน"** บนหน้าเว็บ แล้วกด **อนุญาต (Allow)**
2. กดปุ่ม **"⚡ ทดสอบข้อความ"** เพื่อทดลองส่งข้อความแจ้งเตือนเข้าเครื่องทันที
3. **ระบบแจ้งเตือนอัตโนมัติ:** เมื่อเปิดหน้าเว็บไว้ ระบบจะตรวจสอบตารางเรียน และส่งแจ้งเตือนเตือนความจำให้คุณ **ก่อนเริ่มคาบเรียน 10-15 นาที** อัตโนมัติ

---

## 🚀 วิธีเอาขึ้น Vercel (ฟรี 100%)
1. อัปโหลดโฟลเดอร์นี้ขึ้น **GitHub**
2. ไปที่ [vercel.com](https://vercel.com) แล้วกด **Add New Project** $\rightarrow$ เลือก Repository นี้
3. กด **Deploy** จะได้ลิงก์ `https://your-app.vercel.app` ใช้งานได้ทันที (มี HTTPS ในตัว ทำให้ฟีเจอร์ PWA และ Push Notification ทำงานได้สมบูรณ์แบบ)
